# Complemento Horóscopo

<img src="{{site.baseurl}}/plugin-horoscope/{{site.img}}/horoscope_icon.png" class="pluginLogo" width="100" />

## Descripción

Este complemento permite consultar el horóscopo cada día, ya sea de forma automática o manual.

Cada día hay varias frases disponibles sobre temas como el amor, el dinero, la familia, la salud, etc.
También hay disponible una frase simbólica.

Esto puede resultar muy práctico para facilitarle a alguien el horóscopo del día (por ejemplo, a través de una cámara Netatmo) o mediante TTS todos los días.

## Configuración

El complemento no requiere ninguna configuración específica.

> Es posible configurar una tarea programada (cron) para activar la lectura automática.

<img src="../{{site.img}}/horoscope_actualisation.png" alt="Actualización automática" width="900" />

> El complemento configura la actualización automática a las 5 de la mañana todos los días, por defecto, para los nuevos dispositivos.

Se aplica automáticamente un widget al comando **Signo del zodíaco**
