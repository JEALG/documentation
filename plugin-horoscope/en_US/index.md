# Horoscope Plugin

<img src="{{site.baseurl}}/plugin-horoscope/{{site.img}}/horoscope_icon.png" class="pluginLogo" width="100" />

## Description

This plugin lets you retrieve your horoscope every day, either automatically or manually.

Several quotes are available every day based on themes such as Love, Money, Family, Health, ...
A symbolic phrase is also available.

This can be very handy for providing someone with their daily horoscope (via a Netatmo camera, for example) or via TTS every day.

## Setup

The plugin does not require any special configuration.

> You can set up a cron job to enable automatic meter reading.

<img src="../{{site.img}}/horoscope_actualisation.png" alt="Auto-refresh" width="900" />

> By default, the plugin sets the auto-refresh for new devices to 5 a.m. every day.

A widget is automatically applied to the **Zodiac Sign** command
