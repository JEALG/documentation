## Häufig gestellte Fragen

- Basiert das Plugin auf APIs von Drittanbietern?

  > Nein, das Plugin führt die Berechnung intern anhand des Luftdrucks durch.

- Wozu dient das Plugin?

  > Das Plugin berechnet einen Wettertrend auf der Grundlage der Entwicklung des Luftdrucks in den letzten Stunden
